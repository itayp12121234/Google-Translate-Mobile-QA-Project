# Google Translate Mobile QA Project

Manual Mobile QA project performed on the Google Translate Android application.

## Project Overview

This project focused on testing the main functionality of Google Translate on Android, including functional behavior, usability, permissions, network conditions, application lifecycle, display settings, and Android integration.

The testing process included test planning, exploratory testing, test case design, test execution, defect reporting, and final test results documentation.

## Test Environment

- Device: Poco X5 Pro 5G
- Operating System: Android 14
- HyperOS: 2.0.17.0
- Application: Google Translate
- Final tested version: 10.40.63.1001155243.6-release

## Test Coverage

The project included testing of:

- Text translation
- Language selection
- Voice input
- Camera features
- Saved phrases
- Permissions
- Network behavior
- Offline behavior
- Application lifecycle
- Display and accessibility settings
- Android integration

## Test Results

- Total Test Cases: 94
- Passed: 93
- Failed: 1
- Pass Rate: 98.9%

One Minor severity display defect was identified when using the maximum device font size.
